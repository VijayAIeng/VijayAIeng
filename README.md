Profile
I build machine learning systems that connect model capabilities with usable software. My work spans language models, speech processing, retrieval-augmented generation, and tool-using agents, with an emphasis on inference, integration, evaluation, and deployment.
I work primarily with Python and PyTorch, alongside the libraries and infrastructure needed to take an AI feature from a model experiment to an application. I am particularly interested in the engineering decisions behind reliable AI systems: retrieval quality, latency, model serving, observability, and practical trade-offs between quality and cost.
Areas of focus
- Language model applications, inference, and fine-tuning
- Speech systems, including ASR, TTS, and voice cloning
- Retrieval-augmented generation and hybrid search
- Tool calling, agent workflows, and orchestration
- Model evaluation, deployment, and ML infrastructure
Open to AI/ML engineering opportunities.
